# ТЗ. Тиждень 2. Вхід

Мета: клієнт і адмін можуть зареєструватися і увійти. Дашборд адміна вже має свої віджети, але ще без живих цифр.

Залежить від тижня 1. Наступний тиждень не починається, поки не прийняті три pull request цього тижня.

Макетів немає. Екрани на звичайному Tailwind. Якщо на цей екран уже є макет, його накладає автор екрана в тому ж PR і не змінює поведінку з цього файлу.

## Данило. Вхід адміна і порожній дашборд

Форма входу. Закриті маршрути адмінки без токена повертають на вхід.

Віджети дашборда: завантаженість, активні сесії, виручка за зміну, сповіщення. Значення — нулі або текст «немає даних». Вигадані числа не підставляємо. Живі цифри — тиждень 8.

Підпис «зміна» означає поточну календарну добу, не зміну співробітника.

Готово, коли адмін входить через API тижня 2 і бачить цей каркас.

## Максим. Облікові записи, ролі, OTP

Реєстрація і вхід за email або телефоном і паролем. JWT. Ролі лише `client` і `admin`.

OTP: підтвердити, надіслати код знову, змінити номер або email. Код повертає відповідь dev API. Провайдера SMS чи пошти немає.

Закриті ендпоінти без токена відповідають 401. Чужа роль — 403.

Готово, коли обидві ролі проходять реєстрацію, OTP і вхід, а Swagger описує ці виклики.

## Михайло. Реєстрація і вхід клієнта

Поля: ім’я, нік, телефон, email, пароль, підтвердження пароля, дата народження, згода з правилами.

Кнопки Google, Discord і Steam видимі й неактивні, підпис «скоро». Запиту в ці сервіси немає.

Окремий екран OTP. Після підтвердження клієнт потрапляє далі вже з токеном.

Готово, коли клієнт реєструється і входить через живий API за email або телефоном і паролем.

## Поза цим тижнем

Жива аналітика дашборда, зони, бронь, сесії, соціальний вхід, листи і SMS.

## Здача і рев’ю

Кожен відкриває один pull request тільки на свою частину. У описі — цей файл і що зроблено.

Рев’юер перевіряє:

- [ ] Адмін входить і без токена не відкриває розділи.
- [ ] Віджети дашборда не показують вигадану статистику.
- [ ] Клієнт проходить реєстрацію, OTP і вхід за email і за телефоном.
- [ ] Код OTP видно у відповіді dev API, окремого провайдера доставки немає.
- [ ] Кнопки Google, Discord і Steam неактивні.
- [ ] Запит без токена отримує 401, чужа роль — 403.

Тиждень закритий, коли прийняті PR Данила, Максима і Михайла.
