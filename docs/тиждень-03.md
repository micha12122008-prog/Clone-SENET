# ТЗ. Тиждень 3. Зони

Мета: адмін веде зони і місця, клієнт бачить головну і каталог. Статус місця читається з API в момент відкриття сторінки.

Залежить від тижня 2. Наступний тиждень не починається, поки не прийняті три pull request цього тижня.

Макетів немає. Екрани на звичайному Tailwind. Якщо на цей екран уже є макет, його накладає автор екрана в тому ж PR і не змінює поведінку з цього файлу.

## Данило. Зони, місця, тарифи, ремонт

Список зон і місць. Тип місця: PC, PS, VR. Характеристики. Тариф у гривнях за годину.

Статус місця: вільно, зайнято, бронь, ремонт. Журнал ремонту. Зміна статусу зберігається через API і видна після перезавантаження.

Готово, коли адмін створює зону і місце, міняє статус і бачить журнал ремонту.

## Максим. API зон, місць і тарифів

CRUD зон, місць і тарифів. Запис у журнал ремонту. Переходи статусу місця не виходять за enum тижня 1: вільно, зайнято, бронь, ремонт.

Готово, коли операції описані в Swagger і адмінка тижня 3 працює на цих викликах, а не на локальних моках.

## Михайло. Головна і каталог зон

Головна: логотип, навігація, блок активної броні або сесії, блок сповіщень, правила клубу, QR користувача.

Каталог: спочатку тип PC / PS / VR, потім зона Standard, VIP, Bootcamp, PS-зона або VR-room. Фото залу можна поставити заглушкою. Статуси місць беруться з API під час відкриття сторінки.

Живе оновлення зайнятості без перезавантаження — тиждень 5, разом із сесією. У цьому тижні його немає.

Готово, коли головна і каталог відкриваються з API, а QR користувача видно на головній.

## Поза цим тижнем

Майстер бронювання, чек-ін, старт сесії, WebSocket зайнятості, карта залу.

## Здача і рев’ю

Кожен відкриває один pull request тільки на свою частину. У описі — цей файл і що зроблено.

Рев’юер перевіряє:

- [ ] Адмін створює зону, місце і тариф і зміна лишається після перезавантаження.
- [ ] Статуси місця збігаються з enum: вільно, зайнято, бронь, ремонт.
- [ ] Журнал ремонту пишеться через API.
- [ ] Клієнт бачить каталог зон і статуси місць з API, не з зашитого списку.
- [ ] На головній є QR користувача, правила клубу і блок активної броні або сесії.
- [ ] У diff цього тижня немає WebSocket зайнятості.

Тиждень закритий, коли прийняті PR Данила, Максима і Михайла.
