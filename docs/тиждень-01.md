# ТЗ. Тиждень 1. Каркас

Мета: підняти три частини продукту так, щоб їх можна було зібрати і відкрити. Екранів із логікою ще немає.

Наступний тиждень беруть у вівторок. Нездане з цього тижня лишається боргом і йде паралельно з новим.

Макетів немає. Екрани на звичайному Tailwind. Якщо на цей екран уже є макет, його накладає автор екрана в тому ж PR і не змінює поведінку з цього файлу.

Правила продукту — у [ГРУПА.md](ГРУПА.md).

## Данило. Каркас адмінки

Працює в папці `admin` репозиторія Clone-SENET. Шаблон Vite вже стоїть, його не замінюємо новим проєктом.

React, TypeScript, Vite, Tailwind. Роутер. Клієнт API вміє підставляти токен, навіть якщо входу ще немає.

Меню і маршрути-заглушки:

- Дашборд
- Бронювання
- Зони
- Бар
- Турніри
- Клієнти
- Аналітика

Базовий набір, яким далі користуються всі екрани адмінки: кнопка, поле, таблиця, модальне вікно, бейдж статусу.

Готово, коли збірка і lint зелені, кожен пункт меню відкривається і показує заглушку, а не порожню сторінку.

## Максим. Схема і скелет API

Працює в папці `backend`. Зараз там порожній `package.json`. У цій папці піднімає NestJS, не поруч і не в `admin`.

Міграції PostgreSQL піднімаються з порожньої бази. Swagger віддає контракт. Ендпоінти цього тижня — заглушки з узгодженими DTO, без бізнес-логіки.

Таблиці: користувачі, зони, місця, тарифи, ремонти, броні, допи до броні, сесії, меню, замовлення, позиції замовлення, журнал балансу, платежі, турніри, матчі, заявки, досягнення, сповіщення.

Enum, які далі не перейменовуємо:

- місце: вільно, зайнято, бронь, ремонт
- оплата: готівка, картка, баланс
- замовлення: new, preparing, issued
- турнір: реєстрація, live, завершено

Готово, коли міграції проходять з нуля, а Swagger показує ці сутності і enum.

## Михайло. Каркас клієнта, Docker, CI

Працює в папці `client`. Шаблон Vite вже стоїть. Заставку бере з вайрфрейма OBSIDIAN PC CLUB, вигляд лишається Tailwind.

React, TypeScript, Vite, Tailwind. Splash, короткий онбординг, перемикач мови тільки для підписів оболонки. Тексти інтерфейсу українські.

Docker Compose і GitHub Actions кладе в корінь репозиторія. Compose піднімає `client`, `admin`, `backend` і Postgres. Actions на push: lint і build усіх трьох частин.

Цього тижня обидва фронтенди ходять у заглушки скелета OpenAPI. Живий ендпоінт підключається в той тиждень, коли він з’являється в API.

Готово, коли `docker compose up` піднімає всі сервіси, CI зелений, splash і онбординг відкриваються.

## Поза цим тижнем

Вхід, OTP, живі дані дашборда, бронювання, сесії, бар, турніри, аналітика.

## Здача і рев’ю

Кожен відкриває один pull request тільки на свою частину. У описі — цей файл і що зроблено.

Рев’юер перевіряє:

- [ ] Адмінка збирається, усі сім розділів меню відкриваються заглушками.
- [ ] Міграції з порожньої бази створюють таблиці і чотири enum вище.
- [ ] Swagger відкривається і описує контракт заглушок.
- [ ] `docker compose up` піднімає клієнт, адмінку, API і Postgres.
- [ ] CI на push проганяє lint і build.
- [ ] У diff немає Redis, MUI, другого API-процесу і платіжного шлюзу.

Тиждень закритий, коли прийняті PR Данила, Максима і Михайла.
